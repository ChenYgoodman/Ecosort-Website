The "EcoSort: Intelligent Garbage Classification Website" project addresses the critical gap in China's waste management ecosystem by developing a user-friendly, intelligent platform to enhance public awareness and practice of waste sorting. Our main goal is to develop a user-friendly three-page intelligent website aimed at popularizing garbage classification knowledge, providing intelligent classification queries, enhancing user awareness, and promoting sustainable practices (Figure 1).The website includes an educational introduction page with detailed information on seven categories of garbage, an interactive Q&A page for knowledge assessment, and an artificial intelligence chatbot page that allows users to query garbage types through text and image input.
